# Code of Conduct

## Our Pledge

We want `@cavi-ai/api-client` to be a useful, respectful project for maintainers,
contributors, and users. Everyone participating in the project is expected to
act with care, patience, and professionalism.

## Expected Behavior

- Be welcoming to people with different backgrounds, experience levels, and
  perspectives.
- Keep technical debate focused on ideas, tradeoffs, evidence, and project
  goals.
- Give and receive feedback in good faith.
- Respect maintainers' time by keeping issues and pull requests clear,
  reproducible, and scoped.
- Report security issues privately through the process in
  [`SECURITY.md`](SECURITY.md).

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without explicit permission.
- Repeatedly derailing technical discussions after maintainers ask to refocus.
- Using project spaces to promote spam, scams, or unrelated services.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, restrict
participation, or block accounts when behavior harms the project or community.
Enforcement decisions should be proportionate, documented when practical, and
focused on restoring a productive project environment.

To report a conduct concern, contact the maintainers through GitHub. For security
vulnerabilities, use GitHub private vulnerability reporting instead of public
issues.
